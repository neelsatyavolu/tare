# Tare: notes for agents

- Read DESIGN.md before touching anything visual. No red/blue for political sides, no client JavaScript (CSP has `script-src 'none'`; waiting pages use `<meta http-equiv="refresh">`).
- `npm test` runs inside the Workers runtime with a local D1; `npm run typecheck` must stay clean. Tests that need outlets of a given side read them from `OUTLETS` by side, so they survive a refresh of the outlet list.
- Outlet leans come only from `data/eady2025` (CC0) via `leanOf` in `src/outlets.ts`. Never hand-assign a lean; outlets without a score are `unrated`. Don't use AllSides, MBFC, Ad Fontes or Pew data (licenses don't allow it); Robertson 2018 needs the author's OK first (see `docs/research/bias-datasets.md`).
- `data/outlets.generated.json` is generated by `scripts/discover-feeds.mjs`; edit `data/outlets-extra.json` (ids, names, presets, exclusions) instead. Known outlet ids must stay stable: production items and stories reference them.
- Never store or show article bodies. Items hold headline, feed description (400 chars max), link and the feed's photo URL.
- Every summary sentence and briefing paragraph must cite real sources; `validateWriteup` and `validateBriefing` enforce it. Don't loosen them to get more stories through.
- The build runs hourly and updates today's edition in place. Stories are never deleted (emails link to them); `active` marks the lineup.
- `SAME_EVENT` (0.84) and `BLINDSPOT` thresholds were tuned on real feeds; re-tune against live data before changing them.
- Rotating `LINK_SECRET` breaks emailed links; rotating `AI_TOKEN_KEY` disconnects every reader's AI account.
- `npm run dev` calls Workers AI on the real Cloudflare account.
